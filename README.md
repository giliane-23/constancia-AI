# 🚀 Constância AI

Aplicação web desenvolvida em Python com Streamlit que avalia sua disciplina diária com base em estudo, foco e constância.

## 🧠 Sobre o projeto

O Constância AI calcula uma pontuação baseada em:

- Horas de estudo
- Prática de lógica
- Leitura técnica
- Nível de foco

Com base na pontuação, o sistema gera uma mensagem motivacional dinâmica.

A ideia do projeto é aplicar lógica de programação para transformar disciplina em métricas mensuráveis.

- Estrutura de funções
